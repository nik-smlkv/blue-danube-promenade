# Blue Danube Promenade — сайт (Lakat krivina, Zemun)

Двуязычный статический лендинг: `index.html` — сербская версия, `ru.html` — русская.
Сборка, база данных и серверная часть не нужны.

## Развёртывание

1. Распакуйте архив.
2. Загрузите всё содержимое в корень любого статического хостинга (Nginx, Apache, Netlify, Vercel, S3 и т. п.), сохранив структуру папок.
3. Откройте сайт и проверьте обе языковые версии, 3D-блок «Kvart» и прогулку по квартире.

Требования к серверу:
- Отдавать файлы по HTTP(S). Двойной клик по HTML не подойдёт: 3D-модели грузятся через `fetch`.
- MIME-типы: `.glb` → `model/gltf-binary`, `.webp` → `image/webp`, `.js` → `text/javascript`, `.woff2` → `font/woff2`.
- Включить gzip или brotli для `.js`, `.css`, `.json`, `.html`. Файлы `.glb` уже сжаты (meshopt).
- Самый большой файл — `model/kv-a.glb`, около 7,7 МБ.

Локальная проверка: в папке сайта выполните `python -m http.server 8000` и откройте `http://localhost:8000/`. На Windows можно запустить `start.bat`.

Внешние зависимости — CDN jsDelivr (GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13), подключены в конце `index.html` и `ru.html`. Если CDN недоступен, сайт работает, но без плавной прокрутки и части анимаций. Three.js r170 лежит локально в `vendor/three`.

Форма заявки проверяет поля, но никуда их не отправляет. Чтобы принимать заявки, её нужно подключить к серверу или CRM, обработчик находится в `app.js`.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `ru.html` | страницы SR / RU |
| `styles.css`, `app.js` | общие стили и логика страницы (меню, каталог, форма) |
| `js/intro.js` | вступление: облёт по кадрам из `img/intro/*` |
| `js/kvart.js` | блок 1 «Kvart»: 3D-сцена, слои, подсветки, свободный обзор |
| `js/kvart-look.js` | материалы, небо, солнце, тени и AO для 3D-модели |
| `js/kvart-apt.js`, `js/apt-l55.js` | 3D-прогулка по квартире L5-5 (загружаются по кнопке) |
| `model/kv-a.glb`, `kv-b.glb` | модель здания и территории для десктопа (из проекта 3ds Max) |
| `model/kv-m.glb` | облегчённая модель для телефонов |
| `model/kvart.json`, `context.json`, `sat_*.webp`, `tex/` | подсветки, окружающая застройка, спутниковая подложка, текстуры |
| `plans/` | планировки квартир, мини-план L5-5 |
| `data/` | каталог квартир |
| `vendor/three` | Three.js r170 и нужные модули |
| `fonts/` | шрифты (локально) |

Версии подключаемых файлов помечены параметром `?v=` в HTML и в импортах. После правок увеличьте номер, чтобы браузеры не взяли старую копию из кеша.

## 3D-блок «Kvart»

- Слои: Pregled · Okruženje · Lamele · Dvorište · Prizemlje, режимы Dan / Veče, кнопки масштаба «+ / −».
- На странице обычное колесо мыши листает сайт. Ctrl или ⌘ + колесо масштабирует модель.
- «Slobodan pogled» / «Свободный обзор» открывает модель на весь экран: вращение, сдвиг, колесо, двойной клик для фокуса, Esc для выхода. На телефоне этот режим открывается кнопкой «Открыть 3D-модель».
- «Prošetajte stanom» / «Прогуляться по квартире» — тест 3D-квартиры L5-5 (ламель 5, 1-й этаж). Режимы: вид сверху и прогулка. Управление: мышь вращает камеру, W A S D или стрелки — ходьба, клик по мини-плану — быстрый переход. На телефоне можно идти касанием пола. Квартира стоит в модели квартала на своём месте, поэтому из окон виден реальный вид.
